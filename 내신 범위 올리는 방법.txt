이레 영어 · 내신 범위 올리는 방법

1. 이 폴더의 naesin.js 를 메모장(또는 VS Code)으로 엽니다.
2. exams 목록에 시험을 넣습니다. 학교·학년마다 하나씩 넣으면 됩니다.
   - id      : 시험마다 다른 이름 (예: '2026-2기말-한빛중-2'). 이미 쓰던 id를 바꾸면 학생 기록이 새로 시작돼요.
   - school, grade, title : 학생 화면에 "한빛중 중2 2학기 기말"처럼 보입니다.
   - date    : 시험 날짜 '2026-12-08' 형식. D-day가 보이고, 2주 전부터 "틀린 문제부터 복습" 안내가 나옵니다.
               시험이 끝나고 4일째부터 목록에서 저절로 빠집니다.
   - book, range : 범위 안내 (예: '○○출판사', 'Lesson 5~6'). 적지 않아도 됩니다.
   - words   : ['단어', '뜻'] 목록. 띄어쓰기가 있으면 숙어·표현 문제로, 없으면 단어 문제(뜻 고르기·듣고 고르기·철자 쓰기)로 나옵니다.
   - sents   : ['영어 문장.', '우리말 뜻'] 목록. 문장 해석·단어 배열 문제로 나옵니다.
3. GitHub Desktop 에서 english 저장소를 Push 합니다. 학생이 앱을 다시 열면 '단계 바꾸기'에 시험이 보입니다.

· 교과서 본문을 그대로 옮기기보다 학원에서 만든 단어장·예문을 쓰세요 (교과서는 저작권이 있어요).
· 쉼표(,)와 따옴표(')를 빠뜨리면 파일 전체가 안 읽혀요. 문장 안에 ' 가 있으면 "큰따옴표"로 감싸세요.
  예: ["I'm looking forward to it.", '나는 그것을 기대하고 있다.']
